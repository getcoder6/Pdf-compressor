FAQ

Frequently asked questions

Is this PDF compressor free?

Yes. This starter version has no account requirement and no payment step.

Are my files uploaded?

This version processes the selected PDF in the browser. Your website can later be upgraded to a server-side optimizer for stronger compression.

Why did my PDF sometimes become larger?

Some PDFs are already optimized. Rebuilding a PDF as page images can increase its size, so the tool reports the actual result rather than claiming a reduction that did not happen.

Does compression preserve selectable text?

The browser-only image-rebuild method can turn pages into images, so selectable text, links, forms and some PDF metadata may not be preserved. For a production-grade compressor, use a true PDF optimization engine on the server.
